# Linux-Network-Infrastructure-Lab-
Enterprise network security lab built with pfSense, Suricata IDS/IPS, OpenVPN, Ubuntu, Kali Linux, and Wireshark. Demonstrates secure network segmentation (WAN/LAN/DMZ), stateful firewall policies, Hybrid NAT, VPN-based remote access, attack simulations, intrusion detection, packet analysis, and defense-in-depth security architecture.
